## English

### New Features

- **Runtime config for native mods**: Native mods that register their settings at runtime (like BlockPlacementAnimation) now show a Configure button on the mod detail page, with a full settings editor.

### Fixes

- **Version compatibility with X wildcard**: Mod version patterns using X as an in-segment wildcard (e.g. 1.26.5X.X) now correctly match versions like 1.26.51 instead of being flagged incompatible.

---

## 简体中文

### 新功能

- **原生模组运行时配置**：在运行时注册配置的原生模组（如 BlockPlacementAnimation）现在在模组详情页显示配置按钮，提供完整的设置编辑界面。

### 修复

- **X 通配符版本兼容**：使用 X 作为段内通配符的模组版本号（如 1.26.5X.X）现在能正确匹配 1.26.51 等版本，不再被误判为不兼容。
