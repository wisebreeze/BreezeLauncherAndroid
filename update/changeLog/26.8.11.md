# 26.8.11

## English

### New Features

- **Advanced options**: Create/Edit World now has a shared Advanced tab with world type, flat presets, world seed, and NBT toggles.
- **Custom layer input**: Custom layers row now uses the project's CompactTextField for visual consistency.
- **Flat presets**: Fixed translations (Tunneler's Dream / Snowy Kingdom / Bottomless Pit). Added a preset layers preview (material × height list). The Void preset shows a description instead of an empty table.
- **Expand/collapse animation**: Preset chips and preview card use alpha + expand/shrink transitions driven by the user's animation speed setting.
- **World seed**: Input field with a 26-option seed picker dialog (create world) or a copy button (edit world).
- **Infinite world spawn**: Spawn Y is now randomised between 63 and 70 (sea level).
- **NBT options**: 12 byte toggles (start with map, bonus chest, show coordinates, recipe unlock, fire tick, TNT, mob loot, etc.) + a slider (players sleeping percentage) + a number input (spawn radius, max 128) + a chip group (simulation distance 4/6/8).
- **Clickable toggle rows**: Tapping anywhere on a toggle row flips the switch with a rounded ripple.

### Fixes

- **Top bar tab**: Fixed bold state persisting after navigating back to a parent page.
- **Hardcore mode**: Fixed inability to toggle hardcore on or off.
- **Import flow**: Fixed multiple back-presses needed to exit after repeated import operations.
- **Import button**: Fixed inconsistent text font size.
- **Preset preview**: Removed shadow artifact (dark spot) at the card's top-left corner.
- **Clipboard**: Replaced deprecated LocalClipboardManager with Android ClipboardManager.
- **Code cleanup**: Removed redundant else in exhaustive when; moved seed description out of placeholder and buttons outside the field; tightened seed picker list spacing.

### Refactor

- **Shared component**: Extracted FlatPresetAdvancedTab into ui/contents, shared by Create World and Edit World.

## 简体中文

### 新功能

- **高级选项**：创建/编辑世界新增共享高级选项卡，包含世界类型、超平坦预设、世界种子、NBT 开关等。
- **自定义层级输入框**：改用项目自定义 CompactTextField，风格统一。
- **超平坦预设**：修正翻译（挖掘者之梦 / 冰雪王国 / 无底洞），新增预设层级预览（左材料右高度列表），虚空预设显示描述文本。
- **折叠展开动画**：预设 chips 和预览卡片使用 alpha + 折叠展开动画，受设置动画倍速影响。
- **世界种子**：输入框 + 26 个预设种子选择弹窗（创建世界）/ 复制按钮（编辑世界）。
- **无限世界出生点**：Y 轴在 63-70 之间随机。
- **NBT 高级选项**：12 个 byte 开关（初始地图、奖励箱子、显示坐标、配方解锁、火焰蔓延、TNT 爆炸等）+ 滑块（需要睡觉的玩家）+ 数字输入（重生半径，最大 128）+ chip 选择（模拟距离 4/6/8）。
- **开关行可点击**：整行点击切换，圆角波纹效果。

### 修复

- **顶栏 tab**：修复返回上级页面仍保留加粗的问题。
- **极限模式**：修复无法开启或关闭的问题。
- **导入流程**：修复多次导入后返回需要多次返回动画才能退出。
- **导入按钮**：修复文本字体大小不一致的问题。
- **预设预览**：修复卡片左上角阴影黑点。
- **剪贴板**：修复 LocalClipboard 弃用警告，改用 Android ClipboardManager。
- **代码清理**：移除冗余 else 分支；种子描述移到标题下方，按钮移到输入框外；收紧种子选择弹窗列表间距。

### 重构

- **共享组件**：提取 FlatPresetAdvancedTab 到 ui/contents，创建世界和编辑世界共用。
