## English
### New Features
- **HUD Editor Snapping**: HUD elements and overlay buttons now snap to each other and screen center when dragging in the HUD editor
- **Revamped Mod Config UI**: Gyro and Hotbar Slot inbuilt mod settings pages fully redesigned with category tabs and card-based controls
- **Always Show Toggle**: New "Always Show" option in overlay settings to keep buttons visible in all scenes
- **Hotbar Slot Visibility**: Hotbar Slot mod now supports toggling individual slot visibility
- **Fine-Adjustable Sliders**: Slider options in mod settings now support precise value entry via +/- buttons and tap-to-input
- **Network Diagnostics**: New "Network Diagnostics" option in the top bar overflow menu to test connectivity and latency to Xbox, CurseForge, GitHub, Gitee, Netlify, and Firebase
- **Version Changelog Popup**: After updating, a popup shows the current version's changelog on first launch
- **Virtual Keyboard Mod**: Added Virtual Keyboard as an inbuilt mod
- **WebSocket Event Subscriptions**: Settings → Overlay tab now includes WebSocket enable toggle and event subscription category switches
- **HUD Snap Toggle**: Global HUD element snapping toggle added to both Settings → Overlay tab and in-game overlay Settings tab
- **More Mod API**: Added additional mod API support
### Improvements
- **Gyro Settings Translation**: Improved translations for gyro config options (e.g. "Dead Zone" → "Movement Threshold")
- **Keybind Config Redesign**: Keybind options now use a button + capture dialog instead of a text field
### Fixes
- Fixed inbuilt mod config changes not taking effect immediately

## 简体中文
### 新功能
- **HUD编辑器元素吸附**：在HUD编辑器中拖动时，HUD元素和悬浮按钮会自动吸附到彼此和屏幕中心
- **模组设置页面焕新**：陀螺仪和快捷栏槽位内置模组的设置页面全面改版，采用分类标签和卡片式控件
- **始终显示开关**：悬浮窗设置新增"始终显示"选项，开启后按钮在任何界面都显示
- **快捷栏槽位可见性**：快捷栏槽位模组支持单独控制每个槽位的显示或隐藏
- **滑块微调**：模组设置中的滑块选项支持通过加减按钮和点击输入精确调整数值
- **网络诊断**：顶栏更多菜单新增"网络诊断"选项，可检测网络连通性并测试Xbox、CurseForge、GitHub、Gitee、Netlify、Firebase等网站的访问延迟
- **版本更新日志弹窗**：更新后首次打开会弹窗显示当前版本的更新内容
- **虚拟键盘内置模组**：新增虚拟键盘作为内置模组
- **WebSocket事件订阅**：设置→悬浮窗分类新增WebSocket启用开关和事件订阅类别开关
- **HUD元素吸附开关**：设置→悬浮窗分类和游戏内悬浮窗设置都加入了HUD元素吸附的全局开关
- **更多模组API**：添加了更多模组API支持
### 改进
- **陀螺仪设置翻译优化**：改进了陀螺仪配置选项的翻译（如"死区"改为"移动阈值"）
- **按键绑定选项重做**：按键绑定选项改为按钮+捕获弹窗的形式，操作更直观
### 修复
- 修复了内置模组配置修改后不立即生效的问题
