# 26.7.17

## English

### Fixes

- **Video background playback at non-1.0x speed**: Fixed an issue where entering an Activity with a dynamic (video) background set to a playback speed other than 1.0x could cause the video to fail to play, or stop after roughly 0.5 seconds. The playback speed is now applied only after the player finishes its initial preparation (`STATE_READY`), avoiding interference with audio renderer initialization.
- **World / resource pack / content import from ZIP**: Switched from `ZipInputStream` to `ZipFile` for extraction. ZIP archives created in streaming mode (with a data descriptor and a zero compressed-size field in the local header) now extract correctly instead of failing or producing incomplete output. Affects `.mcworld`, `.mcpack`, and skin/content imports.
- **Safe-area toggle**: The safe-area inset toggle is now respected across all Activities and top bars, not just a subset of screens.
- **Instance display name**: Renaming an instance now also updates the display name of already-installed instances, so the launcher and the installed copy stay in sync.
- **Crash report UI**: Removed the redundant header and divider on the crash-details screen for a cleaner, more minimal layout.
- **French and Turkish translations**: Escaped apostrophes in `shader_loader_desc` (`l'Ore` → `l\'Ore`, `Shader'ları` → `Shader\'ları`) that caused the build to fail with a misleading "Invalid unicode escape sequence" AAPT error.

### Features

- **Shizuku API scaffold**: Added the Shizuku API dependency and a `ShizukuManager` wrapper (lifecycle-aware, with permission/binder state tracking). Not yet called by any feature — lays the groundwork for future elevated operations such as silent APK install or out-of-scoped-storage file access.

### CI / Build

- **Build cache strategy**: The build cache key now includes a hash of all `strings.xml` files, so a translation change no longer restores a stale merged-resources cache that produced phantom AAPT errors.
- **Automatic cache cleanup**: A post-build step now deletes build caches not accessed in the last 7 days, preventing old per-commit caches from piling up and slowing down cache restore-key matching.

## 简体中文

### 修复

- **非 1.0x 倍速视频背景播放**：修复了设置动态（视频）背景且播放倍速非 1.0x 时，进入 Activity 有概率导致视频无法播放或仅播放约 0.5 秒后停止的问题。倍速现在会在播放器完成初始准备（`STATE_READY`）后才应用，避免干扰音频渲染器初始化。
- **世界 / 资源包 / 内容 ZIP 导入**：解压从 `ZipInputStream` 改为 `ZipFile`。以流式模式创建的 ZIP（带数据描述符、本地头压缩大小字段为 0）现在可以正确解压，不再失败或输出不完整。影响 `.mcworld`、`.mcpack` 及皮肤/内容导入。
- **安全区域开关**：安全区域内边距开关现在在所有 Activity 和顶栏生效，不再只覆盖部分页面。
- **实例显示名称**：重命名实例时现在会同步更新已安装实例的显示名称，保持启动器与已安装副本一致。
- **崩溃报告界面**：移除了崩溃详情页冗余的标题和分割线，布局更简洁。
- **法语和土耳其语翻译**：转义了 `shader_loader_desc` 中的撇号（`l'Ore` → `l\'Ore`、`Shader'ları` → `Shader\'ları`），此前未转义的撇号导致构建以误导性的 "Invalid unicode escape sequence" AAPT 错误失败。

### 新功能

- **Shizuku API 脚手架**：添加了 Shizuku API 依赖和 `ShizukuManager` 封装（生命周期感知，含权限/binder 状态跟踪）。目前未被任何功能调用——为后续提权操作（如静默安装 APK、访问作用域外存储）打基础。

### CI / 构建

- **构建缓存策略**：构建缓存 key 现在包含所有 `strings.xml` 文件的哈希，翻译变更不再会恢复到陈旧的 merged-resources 缓存，从而避免幻影 AAPT 错误。
- **自动清理缓存**：新增构建后步骤，自动删除超过 7 天未访问的构建缓存，防止旧的按 commit 存储的缓存堆积、拖慢缓存 restore-key 匹配。
