## English

### Breaking Changes

- **Mod loading refactored**: All mod data (`.so` files and `mods_config.json`) is now stored exclusively in app-private internal storage (`/data/data/<pkg>/files/minecraft/<profileId>/mods/`). The previous Android/data mods directory is no longer used; existing mods are migrated automatically on first launch. This resolves mod loading failures caused by storage path conflicts.

### Fixes

- **Latest beta crash**: Fixed a crash on the latest Minecraft beta caused by duplicate bundled libraries (libpairipcore, libPlayFabMultiplayer, libmaesdk) being extracted from the APK alongside the launcher's own copies.
- **Network navigation crash**: Fixed a crash when navigating away from the game download page while Play API requests were in flight — OkHttp calls are now properly cancelled on activity destroy.
- **Version download**: Fixed several known issues in the version download flow.

### Improvements

- **Latest beta experience**: Various optimizations for the latest Minecraft beta.

## 简体中文

### 破坏性变更

- **模组加载重构**：所有模组数据（`.so` 文件和 `mods_config.json`）现在统一存放在应用私有内部存储（`/data/data/<pkg>/files/minecraft/<profileId>/mods/`）。不再使用 Android/data 模组目录，已有模组在首次启动时自动迁移。此更改解决了因存储路径冲突导致的模组无法加载问题。

### 修复

- **最新测试版崩溃**：修复最新 Minecraft 测试版因重复加载启动器自带的库文件（libpairipcore、libPlayFabMultiplayer、libmaesdk）而崩溃的问题。
- **网络导航崩溃**：修复在 Play API 请求进行中离开游戏下载页面时的崩溃——现在 Activity 销毁时会正确取消所有 OkHttp 请求。
- **版本下载**：修复版本下载流程中的若干已知问题。

### 改进

- **最新测试版体验**：针对最新 Minecraft 测试版的多项优化。
