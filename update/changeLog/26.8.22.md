## English

### New Features

- **Community module**: Added a report button.
- **Overlay panel**: Added a Mods tab for configuring both inbuilt and external mods.
- **Overlay panel**: Added a switch to show the overlay only on the pause screen.
- **App updates**: Uses Shizuku to install updates silently when Shizuku permission is granted.
- **Mods**: Mod content can now be displayed in a list layout.

### Fixes

- **Overlay panel**: Fixed the team page not rendering.
- **NBT editor**: Fixed a crash when expanding lists with a large number of entries.
- **Mods**: Importing mod packages with other supported extensions (e.g. .levipack) now works correctly and shows feedback for unsupported files.

### Improvements

- **Community**: Optimized community resource downloads.
- **Overlay panel**: Improved panel animations.
- **World editor**: Improved editing screen performance and smoothness.
- **Removed**: Archive encryption/decryption option has been removed.

## 简体中文

### 新功能

- **社区模块**：加入举报按钮。
- **悬浮窗面板**：加入模组 tab，可对内置模组和外置模组进行设置。
- **悬浮窗面板**：加入仅在暂停屏幕显示悬浮窗的开关。
- **应用更新**：获得 Shizuku 权限后，将使用 Shizuku 静默更新应用。
- **模组**：模组内容可切换为列表形式显示。

### 修复

- **悬浮窗面板**：修复组队页面无法显示的问题。
- **NBT 编辑器**：修复展开数据过多导致的崩溃问题。
- **模组**：导入其他后缀（如 .levipack）的模组包现在可正常工作，并对不支持的文件给出提示。

### 优化

- **社区**：优化社区资源的下载。
- **悬浮窗面板**：优化面板动画。
- **世界编辑器**：优化编辑世界屏幕性能，提升流畅性。
- **移除**：移除存档加密/解密选项。
