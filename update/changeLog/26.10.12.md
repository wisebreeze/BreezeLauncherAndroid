## English

### New Features

- **Personalization**: Added animated GIF background support. GIFs are classified as image backgrounds (no membership restriction).
- **Overlay panel**: Panel state (selected tab, sub-screen navigation, filter/search, sidebar collapse) and scroll positions are now preserved across panel hide/show cycles.

### Improvements

- **Authentication**: Microsoft and Xbox credentials are now refreshed before launching Minecraft to prevent in-game login failures from expired tokens.

### Fixes

- **AI Assistant**: Fixed a 400 error ("reasoning_content in the thinking mode must be passed back to the API") when using custom model providers with thinking mode in multi-turn conversations.
- **Permissions**: Fixed a crash when tapping the "Grant Permission" button for the install-unknown-apps permission dialog.

### Other

- Removed dead legacy storage migration code (`games/breeze`).
- Extended beta deadline to 2026-12-31.

## 简体中文

### 新功能

- **个性化**：新增 GIF 动态背景支持。GIF 归类为图片背景，无需会员。
- **悬浮窗面板**：面板状态（当前标签页、子页面导航、筛选/搜索、侧栏折叠）和滚动位置在面板关闭/重新打开后自动恢复。

### 优化

- **登录**：启动 Minecraft 前主动刷新微软和 Xbox 凭据，避免因 token 过期导致游戏内登录失败。

### 修复

- **AI 助手**：修复使用自定义模型提供商 + 思考模式时多轮对话报 400 错误（"reasoning_content in the thinking mode must be passed back to the API"）的问题。
- **权限**：修复点击安装未知应用权限弹窗的「授权」按钮时崩溃的问题。

### 其他

- 移除已废弃的 `games/breeze` 旧版存储迁移代码。
- 内测截止时间延长至 2026-12-31。
