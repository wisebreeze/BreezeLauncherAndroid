## English

### New Features

- **Map block & structure operations**: Added block fill/replace and structure placement submenus to the world map. Place structures, paint biomes, and fill regions with blocks directly from the map view.
- **Background image from file**: The background picker now supports selecting an image from the device's file system in addition to the built-in gallery.
- **Staged map edits**: World editor map operations are now staged — review your changes and discard them all at once if needed, without writing to the world until you explicitly save.

### Fixes

- **Mod buttons on HUD editor**: Fixed mod floating buttons being hidden while the HUD editor is open.

### Improvements

- Various detail optimizations and UI refinements.

## 简体中文

### 新功能

- **地图方块与结构操作**：世界地图新增方块填充/替换和结构放置子菜单，支持在地图上直接放置结构、绘制生物群系、用方块填充区域。
- **从文件选择背景**：背景选择器新增从设备文件系统选择图片的功能，除内置图库外提供更多选择。
- **地图操作暂存**：世界编辑器的地图操作现在会被暂存，可随时查看并一键丢弃全部更改，保存前不会写入世界。

### 修复

- **HUD 编辑页模组按钮**：修复 HUD 编辑页面打开时模组悬浮按钮被隐藏的问题。

### 改进

- 部分细节优化与界面改进。
