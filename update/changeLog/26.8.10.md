# 26.8.10

## English

### New Features

- **Mod icons**: Built-in mod overlay buttons now use a circular floating-window background.
- **Log console**: New unified log console tile on the home tab with search, level filters, and copy.

### Fixes

- **Mod icons**: Dropped strokes for a cleaner floating-button look.
- **Log console**: Fixed JVM signature clash, logcat process type, and batched pipeline.
- **Overlay**: Fixed clipboard/SelectionContainer and CurseForge pack download (external cache + integrity check).
- **UI**: CurseForge chips spacing and search/category/sort moved to overlay top bar.

### Improvements

- **Log console**: Full i18n for all supported locales.

### CI / Build

- **Discord**: Release notification with English changelog (markdown embed).
- **Release workflow**: Fixed detached HEAD push to remote main.
