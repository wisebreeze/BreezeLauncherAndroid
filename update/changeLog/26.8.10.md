# 26.8.10

## English

### New Features

- **In-Game Overlay Panel**: Floating button + full panel with Home, Browser, AI, and Settings tabs accessible while in-game. Includes a responsive feature-tile grid and scrollable picker row.
- **AI Assistant**: In-game AI chat that streams replies to Minecraft chat via the `@ai` trigger. Conversation history sidebar (new/switch/delete), character management (replaces single system prompt), memory management with 5 memory tools, custom model configuration, deep-thinking toggle, collapsible reasoning bubbles, stop button during streaming, long-press context menu, Skills + MCP settings, and tool calls (`grep_code`, `search_files`, `adjust_builtin_mod`, `send_ws_command`).
- **Minecraft WebSocket Console**: Built-in WSS console with encrypted websocket support, event subscription category toggles, `.exit`/`.restart` commands, and copy-all-logs.
- **Browser Tab**: GeckoView (Firefox engine) browser with multi-page tab support, custom search engines, User-Agent selection, and a privacy section (DNT / WebRTC / GPC toggles).
- **Unified Log Console**: Home-tab tile showing process logcat (`android.util.Log`) with search, level filters (ERROR/WARN/INFO/DEBUG), pause/clear/copy, and full i18n.
- **World Editor**: NBT containers rendered as expandable tree nodes, save button above tabs with live world preview, and rail preview animation driven by user animation settings.
- **Content Management**: World templates with filter UI, development pack directory scanning and tagging, and CurseForge pack download to external cache with integrity verification.
- **Compatibility Framework**: Launch switch in settings, mod-menu toggle and screen orientation forwarding to the framework, play-time recording, framework content shown in content management, and GitHub mirror download.
- **Account System**: Profile info card, avatar (photo picker + crop + upload), change nickname/password, delete account (3-step dialog), forgot/reset password, silent JWT refresh, and membership subscription with restore-purchase flow.
- **Personalization**: Video backgrounds with volume and speed controls, background mask opacity, collapsible left navigation rail, MD3 dynamic color scheme, and custom internal/external storage path overrides.
- **Instances**: Shortcut creation with icon picker and menu management, multi-select batch operations, world icon preview, sort menu (name/version/updated/install time), per-instance frame-rate option, and remote storage spaces (FTP/SFTP/WebDAV/FileProvider) with drag-to-reorder and connection testing.
- **Mod Icons**: Built-in mod overlay icons now use circular floating-window backgrounds (dark disc + light glyph) instead of bare gray/blue icons, making them read as floating buttons.
- **i18n**: 16 translated languages including Traditional Chinese, Korean, Arabic, German, Italian, and Vietnamese.

### Fixes

- **Log capture**: Switched `logcatProcess` to `java.lang.Process`; resolved JVM signature clash on `LogCollector.paused`; batched logcat pipeline for performance.
- **Overlay**: Fixed `SelectionContainer` import and clipboard `AnnotatedString`; hoisted downloaded counter out of `FileOutputStream` scope; CurseForge packs now download to external cache with integrity check.
- **UI**: Added spacing between CurseForge chips; moved category/sort/search to overlay top bar; fixed touch-slop tap cancellation; fixed mouse motion gating on mouse source.
- **Auth**: Fixed Compose invocation errors in `InGameOverlayManager`; escaped apostrophes in fr/it/tr strings; per-field error hints for empty email/password/code.
- **Anti-tamper**: Abort launch when ApkSignatureKillerPlus injection is detected; SHA-256 signature pin; null-guarded Java platform types passed to Compose `Text`.

### Improvements

- **AI security**: Encrypted AI API keys and custom auth headers at rest; memoised decrypted secrets in memory for the session; client-side rate limiter; migrated ai-chat from Supabase to Netlify Edge Function.
- **Build**: R8 obfuscation scoped to `com.wisebreeze.launcher`; disabled Jetifier; NDK debug symbols set to NONE; Kotlin compiler switched to out-of-process execution; Gradle cache optimization.
- **Performance**: Shared ExoPlayer across all Activities to fix jank; startup signature check moved off the main thread; `dlopen` switched to `RTLD_LAZY` for faster Minecraft library load.
- **Backup**: Support `.levibackup` / `.breezepack` / `.zip` restore; accept LeviLaunchroid `.levibackup` backups on restore.

### CI / Build

- **Discord notification**: Build publishes changelog + APK to the CubeVisage Discord server's app channel on push to main.
- **Release workflow**: `release-on-tag` workflow triggers on release published; attaches the APK; updates `update.json`; syncs to Gitee.
- **CI pipeline**: Always builds signed release; APK signing via SDK apksigner; stale build-cache cleanup.

## 简体中文

### 新功能

- **游戏内悬浮面板**：悬浮按钮 + 全功能面板，含首页、浏览器、AI、设置标签页，游戏中可直接调用。含响应式功能磁贴网格和可滚动选择行。
- **AI 助手**：游戏内 AI 聊天，流式回复到 MC 聊天（`@ai` 触发）。对话历史侧边栏（新建/切换/删除）、角色管理（替代单一系统提示词）、记忆管理含 5 个记忆工具、自定义模型配置、深度思考开关、可折叠推理气泡、流式停止按钮、长按上下文菜单、Skills + MCP 设置、工具调用（`grep_code`、`search_files`、`adjust_builtin_mod`、`send_ws_command`）。
- **Minecraft WebSocket 控制台**：内置 WSS 控制台，加密 websocket、事件订阅分类开关、`.exit`/`.restart` 命令、一键复制日志。
- **浏览器标签页**：GeckoView（Firefox 引擎）浏览器，多标签页、自定义搜索引擎、User-Agent 选择、隐私开关（DNT / WebRTC / GPC）。
- **统一日志控制台**：首页磁贴显示进程 logcat（`android.util.Log`），支持搜索、级别筛选（错误/警告/信息/调试）、暂停/清空/复制、完整多语言。
- **世界编辑器**：NBT 容器渲染为可展开树节点、保存按钮置于标签页上方含实时世界预览、导轨预览动画跟随用户动画设置。
- **内容管理**：世界模板含筛选界面、开发包目录扫描与标记、CurseForge 整合包下载到外部缓存并校验完整性。
- **兼容框架**：设置中启动开关、模组菜单开关和屏幕方向转发到框架、游玩时长记录、框架内容在内容管理中展示、GitHub 镜像下载。
- **账户系统**：资料信息卡片、头像（照片选择 + 裁剪 + 上传）、修改昵称/密码、删除账户（三步对话框）、忘记/重置密码、静默 JWT 刷新、会员订阅含恢复购买流程。
- **个性化**：视频背景含音量和速度控制、背景遮罩透明度、可折叠左侧导航栏、MD3 动态色彩方案、自定义内部/外部存储路径。
- **实例**：快捷方式创建含图标选择和菜单管理、多选批量操作、世界图标预览、排序菜单（名称/版本/更新时间/安装时间）、逐实例帧率选项、远程存储空间（FTP/SFTP/WebDAV/FileProvider）含拖拽排序和连接测试。
- **模组图标**：内置模组悬浮按钮图标改为圆形悬浮窗背景（深色圆盘 + 浅色字形），替代裸灰色/蓝色图标，视觉上更像悬浮按钮。
- **国际化**：16 种语言翻译，含繁体中文、韩语、阿拉伯语、德语、意大利语、越南语。

### 修复

- **日志捕获**：`logcatProcess` 改用 `java.lang.Process`；修复 `LogCollector.paused` 的 JVM 签名冲突；批量 logcat 管道提升性能。
- **悬浮窗**：修复 `SelectionContainer` 导入和剪贴板 `AnnotatedString`；将下载计数器移出 `FileOutputStream` 作用域；CurseForge 整合包下载到外部缓存并校验。
- **界面**：CurseForge 标签间距；分类/排序/搜索移至悬浮窗顶栏；修复触摸阈值点击取消；修复鼠标运动门控。
- **认证**：修复 `InGameOverlayManager` 的 Compose 调用错误；转义 fr/it/tr 字符串撇号；逐字段错误提示（空邮箱/密码/验证码）。
- **防篡改**：检测到 ApkSignatureKillerPlus 注入时中止启动；SHA-256 签名固定；空值保护 Compose `Text` 的 Java 平台类型。

### 改进

- **AI 安全**：AI API 密钥和自定义认证头静态加密；会话内存中缓存解密密钥；客户端限流；ai-chat 从 Supabase 迁移到 Netlify Edge Function。
- **构建**：R8 混淆限定于 `com.wisebreeze.launcher`；禁用 Jetifier；NDK 调试符号设为 NONE；Kotlin 编译器进程外执行；Gradle 缓存优化。
- **性能**：跨 Activity 共享 ExoPlayer 消除卡顿；启动签名检查移出主线程；`dlopen` 改用 `RTLD_LAZY` 加速 Minecraft 库加载。
- **备份**：支持 `.levibackup` / `.breezepack` / `.zip` 恢复；支持 LeviLaunchroid `.levibackup` 备份恢复。

### CI / 构建

- **Discord 通知**：推送 main 时将更新日志 + APK 发布到 CubeVisage Discord 服务器的 app 频道。
- **发布工作流**：`release-on-tag` 工作流在 release 发布时触发；附加 APK；更新 `update.json`；同步到 Gitee。
- **CI 流水线**：始终构建签名 release；通过 SDK apksigner 签名 APK；过期构建缓存清理。
