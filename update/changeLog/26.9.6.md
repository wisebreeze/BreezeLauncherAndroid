## English
### New Features
- **NetEase Music WebView Login**: The music tab's login page now supports an inline WebView login flow (default) alongside the QR code flow. A top-bar switch lets you toggle between "网页" and "二维码" modes. The WebView supports pinch-to-zoom and a refresh button.
### Improvements
- **Mod Menu Layout Persistence**: The mod menu's layout mode (grid/list) is now saved to settings.json and restored on the next session — no more resetting to grid every time you open the panel.
### Fixes
- **Changelog Dialog Empty Content**: Fixed the update changelog dialog showing "暂无最新版本的更新日志内容" (no changelog content) even when the .md file existed. The fetch now uses raw.giteeusercontent.com directly to avoid Gitee's 302 redirect, and auto-dismisses the dialog if the content is genuinely empty.
- **Instance Frame Rate Reset**: Fixed the instance frame rate setting occasionally resetting to "不强制" (not forced) after saving. The isolation, screen orientation, and frame rate are now persisted atomically in a single write to eliminate the race condition.

## 简体中文
### 新功能
- **网易云音乐网页登录**：音乐标签页的登录页新增内嵌网页登录流程（默认），与二维码登录并存。顶栏切换控件可在"网页"和"二维码"模式间切换。网页支持双指缩放和刷新按钮。
### 改进
- **模组菜单布局持久化**：模组菜单的布局模式（九宫格/列表）现在会保存到 settings.json，下次打开时恢复上次选择，不再每次都重置为九宫格。
### 修复
- **更新日志弹窗显示无内容**：修复了更新日志弹窗在有 .md 文件时仍显示"暂无最新版本的更新日志内容"的问题。现在直接使用 raw.giteeusercontent.com 避免 Gitee 的 302 重定向，且内容确实为空时自动关闭弹窗。
- **实例帧率被重置**：修复了保存实例设置后帧率有概率被重置为"不强制"的问题。隔离、屏幕方向和帧率现在以原子方式一次性写入，消除竞态条件。
