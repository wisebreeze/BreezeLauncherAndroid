# 26.8.17

## English

### New Features

- **NBT editor in world settings**: Added an NBT editor to the edit world screen, allowing direct inspection and modification of world-level NBT data without external tools.
- **World encryption / decryption**: Added world encryption and decryption support so users can protect world data at rest and restore it when needed.

### Fixes

- **CurseForge mod downloads**: Fixed an issue where some CurseForge mods could not be downloaded because their `downloadUrl` was null (anti-hotlinking). The launcher now falls back to the `/download-url` endpoint to fetch a temporary link before downloading.
- **Mod manifest recognition on download**: Fixed downloaded mods not preserving the original `manifest.json`. Archive imports (`.zip` / `.breezepack` / `.levipack` / `.tar.gz`) now extract the full archive and preserve `description`, `icon`, `overwrite_files`, `overwrite_folders`, `minecraft_versions`, and other fields, only overwriting launcher-essential keys (`type` / `name` / `entry` / `license` / `link`).

## 简体中文

### 新功能

- **世界设置 NBT 编辑**：编辑世界屏幕新增 NBT 编辑器，可直接查看和修改世界级 NBT 数据，无需借助外部工具。
- **世界加密 / 解密**：新增世界加密与解密支持，用户可对世界数据进行加密保护，需要时再解密恢复。

### 修复

- **CurseForge 模组下载**：修复部分 CurseForge 模组因 `downloadUrl` 为空（反盗链）无法下载的问题。现在当直链缺失时会自动调用 `/download-url` 端点获取临时链接再下载。
- **下载模组 manifest 识别**：修复下载模组未保留原始 `manifest.json` 字段的问题。压缩包导入（`.zip` / `.breezepack` / `.levipack` / `.tar.gz`）现在会解压完整包并保留 `description`、`icon`、`overwrite_files`、`overwrite_folders`、`minecraft_versions` 等字段，仅覆盖启动器必需的关键字段（`type` / `name` / `entry` / `license` / `link`）。
