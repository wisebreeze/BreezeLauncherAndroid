# 26.8.17

## English

### New Features

- **NBT editor**: Added an NBT editor to the edit world screen.
- **World encryption**: Added world encryption / decryption support.

### Fixes

- **CurseForge downloads**: Fixed some CurseForge mods failing to download.
- **Mod manifest**: Fixed downloaded mods not preserving the original manifest.json.

### 新功能

- **世界加密**：新增世界加密 / 解密支持。

### 修复

- **CurseForge 下载**：修复部分 CurseForge 模组无法下载的问题。
