## English

### New Features

- **Microphone access for mods**: Native mods can now use the microphone for voice chat and other audio features.

### Improvements

- **Faster content loading**: World and resource pack lists now load significantly faster with metadata caching.
- **Optimized storage reads**: Content counts on the home screen update more quickly with a dedicated background counter.
- **Indonesian language fixed**: The Indonesian translation now applies correctly when selected.

### Fixes

- **Removed background keep-alive**: Removed the foreground service that prevented the game from pausing when switching apps, reducing battery drain and heat.

## 简体中文

### 新功能

- **模组麦克风权限**：原生模组现在可以使用麦克风进行语音聊天等音频功能。

### 改进

- **内容加载更快**：世界和资源包列表通过元数据缓存大幅提升加载速度。
- **优化存储读取**：首页内容计数通过专用后台计数器更快更新。
- **修复印尼语**：选择印尼语后现在可以正确应用翻译。

### 修复

- **移除后台保活**：移除了阻止游戏切后台时暂停的前台服务，降低耗电和发热。
