## English

### New Features

- **Personalization**: Added animated GIF background support. GIFs are classified as image backgrounds (no membership restriction).
- **Overlay panel**: Panel state (selected tab, sub-screen navigation, filter/search, sidebar collapse) and scroll positions are now preserved across panel hide/show cycles.
- **Overlay**: Added configurable panel toggle keybind (default M) for in-game keyboard shortcut.

### Improvements

- **Authentication**: Microsoft and Xbox credentials are now refreshed before launching Minecraft to prevent in-game login failures from expired tokens.

### Fixes

- **Auto Sprint**: Fixed the auto sprint overlay button not triggering sprint in-game.
- **Overlay buttons**: Fixed overlay buttons being draggable outside HUD editor mode.
- **AI Assistant**: Fixed a 400 error when using custom model providers with thinking mode in multi-turn conversations.
- **Permissions**: Fixed a crash when tapping the "Grant Permission" button for the install-unknown-apps permission dialog.

### Other

- Removed dead legacy storage migration code.
- Extended beta deadline to 2026-12-31.

## 简体中文

### 新功能

- **个性化**：新增 GIF 动态背景支持，归类为图片背景，无需会员。
- **悬浮窗面板**：面板状态和滚动位置在关闭/重新打开后自动恢复。
- **悬浮窗**：新增面板切换快捷键（默认 M）。

### 优化

- **登录**：启动 Minecraft 前主动刷新微软和 Xbox 凭据。

### 修复

- **自动疾跑**：修复自动疾跑悬浮按钮点击后无法触发疾跑的问题。
- **悬浮按钮**：修复非 HUD 编辑模式下仍可拖动悬浮按钮的问题。
- **AI 助手**：修复使用自定义模型提供商 + 思考模式时多轮对话报 400 错误的问题。
- **权限**：修复点击安装未知应用权限弹窗的「授权」按钮时崩溃的问题。

### 其他

- 移除已废弃的旧版存储迁移代码。
- 内测截止时间延长至 2026-12-31。
