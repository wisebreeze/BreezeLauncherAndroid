## English

### New Features

- **Overlay settings tab**: Added an Overlay tab to the settings screen so in-game overlay options can be tuned outside the game.

### Fixes

- **Mod menu button hidden on new versions**: Fixed the mod menu button failing to show on MCPE 1.26.45 due to an outdated isShowingMenu signature; now resolved via vtable index lookup.

---

## 简体中文

### 新功能

- **悬浮窗设置选项**：设置页新增悬浮窗 tab，可在游戏外调整游戏内悬浮窗的相关选项。

### 修复

- **新版本无法显示悬浮窗按钮**：修复 MCPE 1.26.45 上因 isShowingMenu 特征码失效导致模组菜单按钮无法显示的问题，改用 vtable 索引定位。
