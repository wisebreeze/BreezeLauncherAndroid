# 26.8.20

## English

### Fixes

- **World database**: Fixed save size growing on every edit. Each LevelDB write now runs a full compaction so superseded values and tombstones are discarded immediately instead of piling up new SST files.
- **World database**: Added an "Optimise database" button in the Advanced tab that collapses obsolete LevelDB files and deletes stale `db.backup_*` directories and the `level.dat.backup` file left by older launcher builds, reclaiming wasted space.
- **Backups**: The launcher no longer creates a full `db/` backup copy or `level.dat.backup` on every save — these were never useful and caused the world folder to bloat.

## 简体中文

### 修复

- **世界数据库**：修复每次编辑后存档体积增大的问题。每次写入 LevelDB 时现在会立即执行全量压缩，丢弃被覆盖的旧值和墓碑标记，不再堆积新的 SST 文件。
- **世界数据库**：高级选项卡新增「优化数据库」按钮，合并冗余的 LevelDB 文件，并删除旧版启动器遗留的 `db.backup_*` 备份目录和 `level.dat.backup` 文件，回收浪费的空间。
- **备份**：启动器不再在每次保存时创建完整的 `db/` 备份副本和 `level.dat.backup`——这些备份从未发挥作用，反而导致世界文件夹膨胀。
