# 26.8.14

## English

### New Features

- **Community hub**: Added a Community page where users can upload and download resources (skins, texture packs, behavior packs, worlds, and more).
- **Team multiplayer**: Added a Team tab for creating and joining multiplayer sessions over a virtual LAN powered by EasyTier.
- **Update channel picker**: Added a dropdown in Settings to switch the update source between GitHub and Gitee.
- **Launcher-managed Minecraft login**: Re-introduced the toggle that lets the launcher handle Minecraft account login.
- **Mimo v2.5 model**: Added the Mimo v2.5 model to the built-in AI assistant.

### Fixes

- **Spectator mode label**: Fixed spectator mode showing as an "unknown" tag in the world options.

### Improvements

- **Built-in mod zoom transition**: Refined the zoom transition curve for built-in mods using Material 3 FastOutSlowIn easing for smoother animation.
- **Broader mod import support**: Added support for importing `.levipack` and `.breezepack` mod archive formats.
- **Floating window icon color**: Optimized floating window icon colors so single-state mod icons use the `overlay_icon_off` tint for better visibility.
- **Cache cleanup speed**: Parallelized cache cleanup tasks on launch for faster startup.
- **Translation completeness**: Backfilled missing strings across 16 locales (ar, tr, hi, idn, it, pt, fr, de, vi, ru, ko, ja, zh-rTW, and more).
- **Miscellaneous polish**: Various minor UI and detail refinements.

## 简体中文

### 新功能

- **社区中心**：新增社区页面，支持上传和下载资源（皮肤、材质包、行为包、世界等）。
- **组队联机**：新增组队标签页，基于 EasyTier 虚拟局域网创建和加入联机会话。
- **更新渠道切换**：设置中新增下拉切换更新源（GitHub / Gitee）。
- **启动器托管 Minecraft 登录**：重新加入使用启动器登录 Minecraft 的开关。
- **Mimo v2.5 模型**：内置 AI 助手新增 Mimo v2.5 模型。

### 修复

- **旁观者模式标签**：修复世界选项中旁观者模式显示为「未知」标签的问题。

### 改进

- **内置模组缩放过渡**：优化内置模组缩放过渡曲线，采用 Material 3 FastOutSlowIn 缓动，动画更顺滑。
- **更多模组导入支持**：支持导入 `.levipack` 和 `.breezepack` 模组压缩包格式。
- **悬浮窗图标颜色**：优化悬浮窗图标颜色，单态模组图标使用 `overlay_icon_off` 色调，可见性更好。
- **缓存清理速度**：启动时并行化缓存清理任务，启动更快。
- **翻译补全**：补全 16 个语言的缺失翻译（ar、tr、hi、idn、it、pt、fr、de、vi、ru、ko、ja、zh-rTW 等）。
- **细节优化**：多项 UI 与细节打磨。
