## English

### New Features

- **Browser**: Added history, bookmarks, and printing support.
- **Mod list**: Mod icons are now displayed in the list.

### Fixes

- **Mod overlay**: Fixed an issue where mod elements incorrectly snapped to the center of the screen.
- **Mod config**: Fixed an issue where runtime mod configuration was not displayed.
- **Built-in mods**: Fixed scaling issues with built-in mods on version 1.26.50.

### Improvements

- **Crash logs**: Crash analysis log files now use the .txt extension.
- **General**: Various minor detail optimizations.

## 简体中文

### 新功能

- **浏览器**：新增历史记录、书签和打印功能。
- **模组列表**：列表现在支持显示模组图标。

### 修复

- **模组悬浮元素**：修复模组元素异常吸附到屏幕中央的问题。
- **模组配置**：修复模组运行时配置不显示的问题。
- **内置模组**：修复 1.26.50 版本缩放内置模组异常的问题。

### 改进

- **崩溃日志**：崩溃分析日志文件更改为 txt 后缀。
- **通用**：部分细节优化。
