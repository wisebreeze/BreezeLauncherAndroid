# 26.8.15

## English

### Improvements
- **Update download channel**: Optimized the APK update download pipeline. Large APKs are now delivered as split parts via the Gitee release mirror, bypassing Gitee's single-attachment size limit. Each part is verified by MD5 before assembly.

---

## 简体中文

### 改进
- **更新下载渠道**：优化 APK 更新下载链路。大体积 APK 现在通过 Gitee release 镜像以分片方式下发，绕过 Gitee 单附件大小限制，每个分片在拼接前都会校验 MD5。
