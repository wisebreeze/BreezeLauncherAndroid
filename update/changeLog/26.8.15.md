# 26.8.15

## English

### Fixes
- **Crash fix**: Resolved an unexpected crash issue that affected some users.

### New Features
- **Connection settings**: Added a new "Links" settings tab consolidating GitHub download mirror management (select / add / edit / delete mirrors) and the EasyTier relay node selector (moved from the former Team tab).
