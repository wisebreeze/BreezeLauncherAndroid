## English

### New Features

- **Package Manager Screen**: A new screen for browsing, installing, and managing game packages and mod dependencies.
- **Download Version Screen**: A dedicated screen for downloading specific Minecraft Bedrock versions.
- **MCP Server**: The launcher can now act as an MCP server, allowing external AI agents to call launcher tools and develop mods remotely.
- **More GitHub Mirrors**: Added additional GitHub mirror options for faster downloads in regions with poor connectivity.

### Improvements

- **Expanded Mod Type Support**: The launcher now supports more types of mods for broader compatibility.
- **Import with Launch Option**: When importing content, users can now choose whether to launch the game immediately or stay in the launcher.
- **Overlay Performance**: Reduced CPU usage of in-game overlays (FPS, CPS, HUD) by stopping update loops when the game is paused and deduplicating redundant native calls.
- **Translation Refinements**: Improved and localized several UI text strings across all supported languages.

## 简体中文

### 新功能

- **包管理屏幕**：新增包管理屏幕，可浏览、安装和管理游戏包及模组依赖。
- **下载版本屏幕**：新增专用屏幕，用于下载特定的 Minecraft 基岩版版本。
- **MCP 服务**：启动器现可作为 MCP 服务端，允许外部 AI Agent 调用启动器工具并远程开发模组。
- **更多 GitHub 镜像**：新增多个 GitHub 镜像，为网络不佳的地区提供更快的下载速度。

### 改进

- **扩展模组类型支持**：启动器现支持更多类型的模组，兼容性更广。
- **导入时选择是否进入游戏**：导入内容时，用户可选择是否立即启动游戏或留在启动器。
- **悬浮窗性能优化**：通过在游戏暂停时停止更新循环并去除冗余的 native 调用，降低游戏内悬浮窗（FPS、CPS、HUD）的 CPU 占用。
- **翻译文本优化**：改进并本地化了多个界面文本，覆盖所有支持的语言。
