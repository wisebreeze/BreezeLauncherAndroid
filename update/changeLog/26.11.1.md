## English

### New Features

- **World Map**: Added an interactive world map for browsing and managing chunks. Select a region and delete its chunks directly from the map.
- **SNBT Editor**: Added inline SNBT (Stringified NBT) editing for tags, enabling quick bulk edits without drilling into each field.

### Improvements

- **NBT Browser layout refactor**: Unified all NBT tabs (Players, Structures, NBT Search, level.dat) into a consistent file-list browser style with push/pop slide animations and a shared long-press context menu (copy / paste / add child / rename / delete).

## 简体中文

### 新功能

- **世界地图**：新增交互式世界地图，可浏览和管理区块，支持在地图上框选区域并删除区块。
- **SNBT 编辑**：新增 SNBT（字符串化 NBT）内联编辑，无需逐字段展开即可快速批量修改标签。

### 改进

- **NBT 浏览器布局重构**：统一玩家、结构、NBT 搜索、level.dat 各 Tab 为一致的文件列表浏览器样式，加入进入/返回滑动动画，长按菜单统一提供复制 / 粘贴 / 添加子项 / 重命名 / 删除操作。
