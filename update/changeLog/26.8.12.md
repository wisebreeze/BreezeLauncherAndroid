# 26.8.12

## English

### New Features

- **Multiplayer & Invincibility settings in Create/Edit World**: Both the Create World and Edit World screens now include a Multiplayer tab and an Invincibility tab, letting you configure multiplayer-related options and invincibility behaviour alongside the existing world settings.
- **Announcements**: A new "Announcements" entry in the home top bar overflow menu opens a dialog that fetches `announcements.json` from Gitee and renders each entry with its publish timestamp as the heading and a locale-aware Markdown body (Chinese for zh, English otherwise). A 12-hour on-disk cache with a stale-while-offline fallback keeps it snappy.
- **Mod description caching**: The download-mods dialog now persists each GitHub repo's description to disk after the first fetch. Subsequent opens read straight from cache and skip the GitHub API call entirely, so descriptions appear instantly without rate-limit pressure.

### Fixes

- **Hardcore mode toggle**: Fixed the issue where flipping the hardcore mode switch did not actually apply to the world — the toggle now correctly writes through to the level data.

### Improvements

- **Tab navigation animation**: Switching between the four top-level Activities (Launch / Instances / Settings / About) now uses a consistent alpha cross-fade instead of the default Activity slide, including the "back to Launch" path that previously fell back to the system animation.

## 简体中文

### 新功能

- **创建/编辑世界新增多人游戏与无敌模式设置**：创建世界与编辑世界界面新增「多人游戏」和「无敌模式」选项卡，可在原有世界设置旁直接配置多人游戏相关选项与无敌行为。
- **公告**：首页顶栏溢出菜单新增「公告」入口，点击后从 Gitee 拉取 `announcements.json`，以发布时间作为标题、按语言环境渲染 Markdown 正文（中文显示中文版，其他语言显示英文版）。内置 12 小时磁盘缓存，离线时回退上次缓存。
- **模组描述缓存**：下载模组弹窗在首次通过 GitHub API 获取仓库描述后将其持久化到磁盘，后续打开直接读缓存、不再请求 API，描述瞬间显示，同时降低速率限制压力。

### 修复

- **极限模式开关**：修复极限模式开关切换后未真正写入世界数据、设置不生效的问题。

### 体验优化

- **Tab 切换动画**：首页、实例、设置、关于四个顶级 Activity 之间的切换统一为 alpha 交叉淡入淡出，包括此前会回退到系统默认动画的「返回首页」路径。
