# 26.8.12

## English

### New Features

- **Multiplayer & Invincibility settings**: Create World and Edit World now include multiplayer and invincibility options.
- **Announcements**: Added an Announcements entry in the top bar menu to view publisher notices.
- **Mod description caching**: Mod descriptions are now cached after the first load for faster display.

### Fixes

- **Hardcore mode**: Fixed the hardcore mode toggle not taking effect.

---

## 简体中文

### 新功能

- **多人游戏与无敌模式设置**：创建世界和编辑世界新增多人游戏与无敌模式选项。
- **公告**：顶栏菜单新增「公告」入口，可查看发布者公告。
- **模组描述缓存**：模组描述首次加载后缓存，显示更快。

### 修复

- **极限模式**：修复极限模式开关不生效的问题。
