## English
### New Features
- **Mod download activity**: Added a dedicated mod download activity, replacing the old dialog with a full-screen experience
- **New mod API**: Added a new mod catalog API (LeviModHub) with community mod source, search, tag filter, sort and MC version compatibility check
- **Minecraft 1.26.50**: Supported Minecraft 1.26.50.00 with preloader signature rules
### Improvements
- **Home content count**: Optimized home page content counting speed with fast directory counting, skipping full content parsing
- **Gyroscope mod**: Optimized gyroscope mod with deadzone fix
- **Install progress dialog**: Optimized install instance progress dialog by hiding empty title to remove top blank space
- **Top bar tabs**: Replaced top bar text tabs with icon buttons, with tooltips and tab highlight on MainActivity home screen
- **Mod screen empty state**: Optimized mod screen empty state placeholder with an Extension icon and hint text
- **Screen transition animations**: Optimized screen transition animations with alpha fade-in for entering activities, fade-in for MainActivity when brought forward via CLEAR_TOP, and eliminated black flash during cross-fade transitions

## 简体中文
### 新功能
- **模组下载 Activity**：新增独立的模组下载 Activity，用全屏体验替换旧的弹窗
- **新模组 API**：新增模组目录 API（LeviModHub），支持社区模组来源、搜索、标签筛选、排序和 MC 版本兼容性检查
- **Minecraft 1.26.50**：支持 Minecraft 1.26.50.00，添加预加载签名规则
### 改进
- **首页内容数量统计**：优化首页内容数量统计速度，采用快速目录计数，跳过完整内容解析
- **陀螺仪模组**：优化陀螺仪模组，修复死区问题
- **安装实例进度弹窗**：优化安装实例进度弹窗，隐藏空标题以移除顶部空白
- **顶栏 tab**：顶栏文字 tab 替换为图标按钮，带 tooltip 和 MainActivity 首页 tab 高亮
- **模组屏幕空状态占位**：优化模组屏幕空状态占位，显示 Extension 图标和提示文字
- **屏幕过渡动画**：优化屏幕过渡动画，进入 Activity 时 alpha 淡入，MainActivity 经 CLEAR_TOP 回前台时也淡入，消除 cross-fade 过渡时的闪黑
